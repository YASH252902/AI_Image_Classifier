# 👁️ ClassiVision - AI Image Classifier

🚀 **Live Demo:** [ClassiVision Web App](https://image-classifier-frontend-h9za.onrender.com)
⚙️ **Backend API Docs:** [FastAPI Swagger UI](https://image-classifier-api-ltiq.onrender.com/docs)

## 📌 Overview
ClassiVision is a full-stack, AI-powered web application that identifies objects in uploaded images in real-time. It doesn't just stop at classification—it automatically fetches relevant biological or historical context from Wikipedia for the identified object, providing a rich, educational user experience.

## ✨ Features
* **Real-Time Classification:** Powered by TensorFlow and MobileNetV2 for fast, lightweight inference.
* **Contextual Knowledge:** Integrates with the Wikipedia API to provide instant summaries and links about the predicted object.
* **Premium UI/UX:** Built with a modern glassmorphism aesthetic, drag-and-drop file handling, and responsive design.
* **Cloud Deployed:** Fully hosted on Render with separate microservices for the web interface and the machine learning API.

## 🛠️ Tech Stack

**Backend:**
